مشروع تطبيق سجل القضايا - Android

المشروع يحتوي على واجهة سجل القضايا السابقة داخل تطبيق Android يعتمد على WebView.
الوظائف الموجودة: الحصر، القضية، الاسم، الحكم، العنوان، البحث الشامل، التعديل والحذف، كلمة مرور، نسخ احتياطي واستعادة.
البيانات محفوظة محليًا داخل تخزين WebView على الهاتف.

مهم: هذا مجلد مصدر مشروع Android Studio وليس ملف APK جاهزًا للتثبيت.
لإنشاء APK:
1) افتح Android Studio واختر Open ثم اختر مجلد CaseRegister.
2) انتظر مزامنة Gradle وتنزيل مكونات Android المطلوبة.
3) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4) سيظهر ملف APK داخل app/build/outputs/apk/debug/.

ملاحظة: الأيقونة المصممة مستوحاة من شارة الشرطة المصرية وليست شعارًا رسميًا معتمدًا.
